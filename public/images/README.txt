Put your images here. File names must match the paths in src/data/content.js.

  profile.jpg            hero portrait (4:5, about 1200x1500)
  about.jpg              About section photo (3:4)
  journey/               cover + gallery photos for each Journey card  (e.g. ncc-cover.jpg, ncc-1.jpg)
  projects/              one cover per project, named after its slug    (e.g. ende-coder.jpg) 16:10
  reels/                 poster image for each achievement reel         (e.g. iche.jpg)         16:10

Tip: keep each image under 400 KB (use JPG or WebP). While `npm run dev` runs, an empty slot shows
the exact file path it expects.
